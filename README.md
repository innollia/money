# 월 100만 원 미만 수익 탐색

목표: 월 순수익 5만~50만 원 우선, 상한 100만 원 미만. 조사량과 별도로 실제 지원·거래·입금을 측정한다.

## 작업 전달

사용자가 커넥터다. 주 에이전트가 작업 문서를 작성하면 사용자가 서브에이전트에 전달한다. 서브에이전트는 이 저장소를 읽고 작업한 뒤 보고서를 GitHub에 올린다. 사용자가 결과 링크를 주 에이전트에 돌려준다. 자동 호출·자동 재위임은 하지 않는다.

1. `일 보내기/01_근거리근로_현금화기준선.md`
2. `일 보내기/02_재택AI작업_계정확인전환.md`
3. `일 보내기/03_기술외주_첫수주검증.md`

01~04 보고서 수령·검토 완료(2026-10-18). 04는 문의 초안·조건부 카드 작성 완료이며 현실 실행 준비는 사용자 조건 확인 대기다. 추가 조사 위임 없이 사용자 가용시간·진행 의향·기존 계정 유무를 회수한다. 실제 문의·지원·입금 검증은 0건이다.

- [회수 완료: 현실 실험 설계 보고서](보고서/04_현실실험설계.md)
- [회수 보고서 검토](문서/01차_보고서회수_검토.md)
- [실행 기준 v1.2](문서/실행기준_v1.2.md)
- [원본 계획·과거 실사](자료/원본_v1.1_과거실사.txt)
- [진행 현황](진행현황.csv)
- [보고서 제출 규격](보고서/제출규격.md)

기준일: 2026-10-18, Asia/Seoul. 아직 서브에이전트 전달·실행·지원·판매·입금이 완료되었다고 기록하지 않는다. 과거 실사 링크와 보수는 재검증 전이다.

시트는 필요하면 `진행현황.csv`를 가져온다. 현재 정본은 GitHub다. 보고서 회수 후 주 에이전트가 진행 현황과 비교 결론을 갱신한다.
