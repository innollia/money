## 6. 사용자에게 보낼 최소 회수 양식 (한 번에, 비민감 값만)

아래 한 줄을 복사해 빈칸만 채우도록 제시. **사용자의 답은 아직 미수신**이므로 빈칸으로 보존.

> **근로 문의 의향** [예/아니오/보류] · **가능 요일** [토/일/둘 다/불가] · **해당 요일 가능한 시간대** [예: 토 12~18시] · **1회 현장 근무 가능 시간** [4/5/6시간 등] · **왕복 이동·준비·근무·추가 응대 합친 주당 최대 시간** [__시간] · **지속 가능한 근무기간** [__개월] · **기존 계정** OneForma [있음/없음], Prolific [활성/대기/없음], Upwork [있음/없음].

- 질문 1(근로 의향): **예**면 L01 조건·채널 사전 검토, **아니오/보류**면 실제 문의하지 않고 기존 계정 유무만 판정.
- 질문 2(요일·현장 근무·총시간): L01 주 1일 4~6시간과 전체 투입 상한 충족 가능 여부. **현재 주 2~6시간은 계획의 비교 가정일 뿐 본인의 확정 시간이 아님**. 불가하면 L01을 자동 지원하지 않고 사용자 선택에 따라 L02/기존 계정 분기.
- 질문 3(근무기간): 1년 의무 수용 불가일 때 매머드가 **협의 불가**라고 회신하면 L01 탈락. 리베도 3~6개월 협의 조건과 비교.
- 질문 4(기존 계정): **있는 계정의 비민감 상태만** 다음 화면 확인을 요청. 없는 계정은 가입하지 않고 보류.
- **절대 요청하지 않을 것**: 주민등록번호·신분증·계좌번호·전화번호·로그인 이메일·비밀번호·인증코드·결제정보·비공개 작업 원문·화면 캡처.

## 7. 수익·시간 비교와 실행기록

**실제 관측 상태(이번 작업)**: 문의 0 / 지원 0 / 신규 가입 0 / 인증 0 / 응시 0 / 유료 입찰 0 / 판매 게시 0 / 계약 0 / 사용자 실제 입금 검증 0. 이는 **이번 위임의 실행 실적**일 뿐 사용자의 과거 근로·수익이 없었다는 주장이 아님.

**담당 01 보고서의 조건부 근로액**(시급은 광고상 수치, 세전·공제/교통/시간 미반영):
- 매머드: 표시 6시간 중 5.5h 유급 가정 **60,500원**, 6h 전부 유급 가정 **66,000원**. 하루만 근무 가능한지 자체가 아직 미확인.

- 실질 시간당 세전 순수익 `=(실제 수령액 - 교통·도구·입찰·환전 등 직접비)/(공고 확인+지원/영업+왕복이동+준비+무급휴게+실제 근로/작업+수정+대기+정산의 총시간)`. 근무시간만 분모에 넣지 않음.
