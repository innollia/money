## 가격 미확정 조건부 계산 (근로 비교 대기)

- `보고서/01_근거리근로.md`는 **2026-10-18 조사 시점에 존재하지 않음**. 동일 시간 정의로 근로 기준선 직접 비교 **대기**. 공통 문서/다른 보고서 미수정.
- 일반식: `n건 계약의 조건부 세전 현금화 가능액 = Σ(실제 계약액 × (1-개별 수수료율)) - 실제 유료 Connects 비용 - 실제 출금비용 - 툴/환전/은행 직접비`. **현금 실적은 실제 출금·입금 확인 전 0원**. 수주 없이 Connects를 구매했다면 매출 0에 비용 발생.
- `n=0`: 지급 확인 **$0**; 실제 무상 Connects만 쓰면 현금지출 0일 수 있으나 영업시간은 >0 가능. 유료 Connects 구매 시 음수.
- 단지 **제시 예산 $10**과 공식 수수료 0~15%를 가정한 1건 시나리오: 계약이 실제 $10이고 정산 완료·한국 원화 직접출금 1회라면 수수료 차감 후 **$8.50~10.00**, 출금비 $0.99 반영 **$7.51~9.01** (추가 Connects·환전·은행비·세금 제외). **수주/지급/가격 보장이 아님**.
- 같은 가정 2건 각 $10, **출금 1회로 합산** 시 **$16.01~19.01** (추가 직접비·세금 제외). 2번 따로 출금하면 수수료 추가. $20 계약 시 금액은 두 배 단순 비례 **출금 수수료 제외**; 동일식으로 재계산해야 함.
- 실질 시간당 세전 순수익 = `(실제로 지급받은 금액 - 모든 직접비) / (공고 검색+제안+대기+상담+재현+개발+수정+정산의 실제 총 시간)`. 수주 0건에서도 이 분모를 반드시 기록. 현재 시간 미측정으로 숫자 시급·월 기대수익 계산 불가.
