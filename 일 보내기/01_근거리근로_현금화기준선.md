# 01 근거리 근로·현금화 기준선

## 그대로 전달할 프롬프트

저장소 https://github.com/innollia/money 의 최신 main을 읽고 아래 작업을 수행하라. README.md, AGENTS.md, 문서/실행기준_v1.2.md, 자료/원본_v1.1_과거실사.txt, 보고서/제출규격.md를 먼저 읽어라. 사용자가 커넥터이므로 다른 에이전트를 부르거나 주 에이전트에게 자동 메시지를 보내지 마라.

목표: 잠실새내 출발 근거리 근로 중 실제 지원 준비로 넘어갈 수 있는 조건을 정리하고 기술 외주와 비교할 근로 기준선을 만든다. 플랫폼 목록 확장이 목적이 아니다.

우선 대상: 매머드익스프레스 잠실종합운동장점(알바몬 119798104), 리베이벤트 서울웨딩타워 근무, KFC 잠실새내점(알바천국 147015132). 원문 링크와 주 에이전트 접근 실패 기록을 확인한다. 고졸 이상 공차는 자격 부적합 과거 사례로만 보존한다.

1. 각 공고 현재성·성인 고교 재학생 자격·주말 하루 4~6시간 가능 여부·최소 근무기간·유급/휴게 시간·첫 근무·첫 지급을 확인한다. 광고상 시급과 실수령을 구별한다.
2. 기존 후보가 전부 부적합/접근 불가이면 공식 활성 대체 공고 최대 2건만 찾는다. 같은 업체 중복 공고는 합친다.
3. 공개 자료로 알 수 없는 단일 근무 허용·단축 근무·배정 빈도는 연락 필요로 분리한다. 반복 검색하지 않는다. 실제 연락은 하지 않는다.
4. 실제 공고를 대상으로 바로 보낼 문의 초안 1개와 지원 전 입력 항목을 작성한다. 연락처는 공식 공고에 있는 경로만 기록한다. 개인정보를 채워 넣지 않는다.
5. 시급·유급시간·왕복시간·비용이 확인된 범위로만 기준선을 계산한다. 이동 미확인이면 조건부 계산과 누락 항목을 표시하고 임의 실질시급을 만들지 않는다.

공수 상한: 이번 차수 60분. 답이 다음 행동을 바꾸지 않으면 조기 중단. 로그인·연락이 필요한 답은 사용자 확인 필요로 전환한다. 제한에 못 끝낸 항목은 미완료로 보고한다.

완료 조건: 최대 3개 우선 후보와 필요시 대체 2개 이내의 판정, 근거, 비교 가능한 기준선 또는 계산 불가 사유, 최우선 1건의 구체적인 문의·지원 준비물. 채용 성공이나 실제 수입 확보로 표현하지 않는다.
