# 02 재택 AI 작업·계정 확인 전환

## 그대로 전달할 프롬프트

저장소 https://github.com/innollia/money 의 최신 main을 읽고 작업하라. README.md, AGENTS.md, 문서/실행기준_v1.2.md, 자료/원본_v1.1_과거실사.txt, 보고서/제출규격.md를 먼저 읽어라. 사용자가 커넥터다. 재위임·자동 메시지 금지.

목표: 재택 작업의 공개 검증을 끝내고 계정에서만 확인되는 조건을 사용자 행동으로 전환한다. 모집 존재를 배정·수입 증거로 취급하지 않는다.

대상: OneForma Audio Transcription Quality Reviewer, Outlier 한국어 Android 평가(4729398005), Outlier OpenClaw Agent Builder. 보조 대상으로 Prolific만 확인한다. 시간 기준 부적합 OneForma 다른 모집을 재검색하거나 플랫폼 목록을 확대하지 않는다.

1. 원문과 현재 공식 모집·정책을 비교한다. 보수 범위·국가·자격·기기·최소시간·AI/자동화 허용·한국 지급 경로를 주장별로 구분한다. 직접 조항 URL을 확보한다.
2. OneForma 정산에 대한 과거의 주간/격주·2~3영업일·최소 $10 주장을 사실로 계승하지 말고 정확한 공식 근거가 있는지 판정한다. 일반 정책이 개별 계정·프로젝트에 적용되는지도 구분한다. 근거가 없으면 확인 불가/과거 주장 미검증.
3. OneForma URL 404와 Outlier 모집 본문 미노출은 공식 대체 경로 1회만 확인한다. 현재 공고를 못 찾으면 현재성 미확인으로 보류한다.
4. 계정별 보수·실제 지급수단·배정량·대기열·시험 결과는 사용자 확인 필요로 분리한다. 어떤 메뉴/화면에서 어떤 비민감 값을 확인해야 하는지, 답이 통과·탈락·보류에 미치는 영향을 작성한다. 메뉴를 직접 보지 못하면 메뉴 경로도 추정임을 명시한다.
5. 최우선 1개에 대해 가입/인증/지원 승인 단계를 구분한 실행 카드와 입력 체크리스트를 준비한다. 실제 가입·인증·시험·지원은 하지 않는다. 광고상 최고시급으로 월수익 계산 금지.

공수 상한: 이번 차수 60분. 공개 답이 없으면 반복 검색 중단. 계정이 필요한 사실은 공개 검색으로 대체하지 않는다.

완료 조건: 후보별 공개 확인 종료점, 기존 정산 주장의 유지/정정/미확인 판정, 사용자가 답할 최소 확인 항목, 최우선 1개 실행 카드. 확률·실제 배정·실수령은 미관측이면 공란/미확인.
