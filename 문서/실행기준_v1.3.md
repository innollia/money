# 수익 탐색 실행 기준 v1.3

2026-10-18 사용자 정정 반영. v1.2의 검증·수익 계산·중단 기준은 유지하되 아래 항목이 이전 우선순위를 대체한다. 원본 자료·01~04 보고서는 당시 기록으로 보존한다.

## 우선순위

- 재택·온라인 수익 우선. 오프라인 실제 알바는 최대한 후순위.
- 매머드 문의를 첫 행동으로 정한 04의 권고는 현행 지시가 아니다. 근로 의향·주말 근무기간을 먼저 질문하지 않는다.
- 근로는 기회비용 비교 자료로 유지한다. 온라인 수익이 근로보다 낮다는 이유만으로 오프라인 근로를 자동 추천하지 않는다. 온라인 내 효율·유연성·실제 배정을 비교한다.
- 가입은 사용자가 실시간 진행 중이다. 구체 플랫폼·완료 여부는 아직 미확인. 기존 계정만 확인하던 제한은 폐기하며 신규 가입을 반복 요구하지 않는다. 가입 진행은 심사·유급 배정·한국 출금 통과를 뜻하지 않는다.
- 사용자가 직접 진행하는 가입은 해당 서비스에서 처리한다. 에이전트에게 가입·본인인증·지원·계약을 대행하라는 포괄 승인은 아니다.

## 일정 적용

사용자가 지정한 Notion 라우팅 페이지에서 학교 시간표·실행 인덱스·관련 일정 행을 실제 조회했다(2026-10-18). 정확한 개인 시간표·학교/교사·사생활 원문 및 페이지 ID는 공개 저장소에 복제하지 않는다.

- 학교·통학·고정 일정을 먼저 제외한다. 하교 이후 전체 시간이나 달력의 빈칸을 수익 작업 가능시간으로 확정하지 않는다.
- 수업·점심 사회시간에 일감을 자동 배치하지 않는다. 시험·행사 등 일회성 일정이 반복 시간표보다 우선한다. 학교 전체 행사와 개인 참석 확정은 구별한다.
- 비동기·중단/재개 가능한 짧은 작업을 우선 검토한다. 10~20분 계정 확인 블록은 제안 상한이며 사용자 실제 가용시간 확정값이 아니다.
- 주 2~6시간은 비교 가정으로만 유지한다. 계획 배치가 실제 필요할 때 주 에이전트가 비공개 Notion 현재값을 다시 확인한다. 서브에이전트에게 광범위한 개인 Notion 탐색을 시키지 않는다.

## 다음 행동

사용자가 가입을 마친 플랫폼명·상태만 회수한다. 모든 계정 완료를 기다리지 않고 먼저 열리는 1개부터 진행한다. 공개 질문 재검색보다 실제 표시된 모집·자격·보수·최소시간·유급 작업 노출·한국 지급 경로를 확인한다. 비공개 프로젝트 원문·캡처·시험 답안·인증자료는 받지 않는다. 공개 가능한 서비스명·예/아니오·숫자로만 회수한다.

Outlier의 학력 예외, OneForma 현재 프로젝트/지급 충돌은 미확인으로 유지한다. 가입 성공만으로 해소되지 않는다. 조건 불일치면 유료 작업/시험을 밀어붙이지 않는다. Prolific 대기열은 유급 배정이 아니다.

서브에이전트 후속 작업은 일 보내기/05_재택계정_첫유급작업전환.md. 현재 계정 입력 미수신이므로 조건부 전달 준비 상태다. 입력이 없으면 이전 보고서 재요약·플랫폼 확대 대신 필요한 최소 질문만 반환한다.
