# 01차 보고서 회수 검토

회수일: 2026-10-18. 기준 커밋: 36391654e3c0cbed7eb55cca2197c49b03fa0ba3(main). 대상: 보고서/01_근거리근로.md, 02_재택AI작업.md, 03_기술외주.md. 아래는 제출물의 논리·범위 검토이며 외부 링크를 독립 재검증한 결과가 아니다.

## 회수 판정

| 작업 | 제출물 | 남은 핵심 조건 | 다음 행동 |
|---|---|---|---|
| 01 | 수령·부분완료 | 주말 하루 허용·계약기간·재학생 수용·실제 유급/이동/급여 | 매머드 문의 준비를 첫 행동으로, 리베를 대안으로 묶음 |
| 02 | 수령·부분완료 | OneForma 현재 개인 공고·보수·지급, Outlier 학력 예외/경력, Prolific 대기열 | 기존 계정 확인만 우선. 신규 가입·지원은 따로 결정 |

01의 매머드 모집·10/22 마감, 02의 공식 지급 규정 충돌·학력 조건, 03의 저실적 계약 사례는 모두 **담당자 확인 보고**다. 주 에이전트의 독립 검증으로 표현하지 않는다. KFC 지정 공고 마감도 동일하다.

## 통합 시 보정

- 근거 등급: 원계획의 B는 복수 독립 사례다. 01·02는 검색 색인에도 B를 부여했고 03은 직접 403인 공고 색인에 A를 부여했다. 이 등급은 공통 등급으로 수용하지 않는다. 자료 유형(원문/색인/후기)과 직접 열람 여부를 보존하고, 현재성·자격·계약·지급 주장을 따로 평가한다. 색인만으로 현재 활성 A 통과 금지.
- Outlier: 사용자 조건은 고교 재학이다. 전문학사 보유 여부를 반복 질문하기보다 **고교 재학자에게 적용되는 개별 공고의 명시적 예외가 미확인**이라는 장애로 남긴다. 일반 FAQ와 학생 가능 문구만으로 적격/탈락 확정 금지. 예외를 찾겠다는 반복 검색도 중단한다.
- OneForma: 주간/격주와 월별 지급 안내의 충돌이 해소되지 않았다. 2~3영업일·최소 $10도 사용자의 첫 지급 조건으로 채택하지 않는다. 개별 계약/계정 표시를 확인하기 전 첫 입금 날짜 미산정.
- 외주: 저실적 판매자 사례는 사용자 첫 계약 성공률이 아니다. 완료 계약명 일치만으로 공고와 거래의 동일성을 완전 확정하지 않는다. 현재 활성 수요·정확한 계약액·입금액은 여전히 미확인.
- 근로 기준선: 광고 단가를 이용한 조건부 계산만 있다. 실질시급 확정값은 없다. 법률·급여 공제 관련 내용은 실제 계약 판단 시 공식 원문을 확인하고, 이번 문서에서는 보고서의 계산 가정으로만 취급한다.
- 03의 '01 보고서 없음'은 작업 당시 상태다. 이제 회수되었으나 01 자체의 실제 시간·비용이 없으므로 숫자 우열 비교는 계속 보류한다.
- 모든 작업 소요시간 미측정. 공수 상한 준수·조사 시간 효율은 확인 불가. 후속은 시작/종료 시각과 실제 활동 시간을 기록한다.
- 아직 자격·정산 필수조건을 모두 통과한 후보와 확정 실험은 없다. 문의 초안 준비와 실험 실행 준비 완료를 구분한다.

## 다음 지시

04를 전달 가능으로 전환한다. 추가 플랫폼 조사·후보 확대·새 상품 제작 없이, 근로 1건의 문의 카드와 최소 사용자 입력 양식을 완성한다. 사용자 정보가 없어도 조건부 초안은 완성하고 누락값을 명시한다. 실제 연락·지원·가입은 수행하지 않는다.

사용자 입력은 실제 가용 요일/시간·가능 근무기간·근로 문의 의향, 기존 계정 보유 여부부터 묻는다. 계정 없는 서비스의 가입·인증·지급 연결을 지금 요구하지 않는다. 개인정보·비공개 작업 원문 수집 금지.

실적: 이번 위임의 연락 0·지원 0·계약 0·입금 검증 0. 사용자 과거 활동을 뜻하지 않는다. 전체 발굴 40~60/기본 15~20/심층 6~8 목표 완료도 선언하지 않는다.
